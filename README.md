LETRAR+ 🎓📚

O LETRAR+ é um protótipo de jogo educacional desenvolvido para auxiliar o processo de alfabetização infantil por meio de atividades interativas e lúdicas. O projeto busca tornar a aprendizagem da leitura e da escrita mais dinâmica, estimulando o reconhecimento de letras, sílabas e palavras de forma divertida e envolvente.

Objetivos
Incentivar a alfabetização infantil.
Desenvolver habilidades de leitura e escrita.
Promover a aprendizagem por meio da gamificação.
Oferecer uma ferramenta educacional de apoio para alunos e professores.
Funcionalidades
Atividades de identificação de letras e sílabas.
Associação entre imagens e palavras.
Sistema de pontuação e progresso.
Interface intuitiva e amigável para crianças.
Feedback imediato para reforçar o aprendizado.
Tecnologias Utilizadas
HTML5
CSS3
JavaScript
Público-Alvo

Crianças em fase de alfabetização, educadores e instituições de ensino que buscam recursos digitais para apoiar o desenvolvimento da leitura e da escrita.

Status do Projeto

🚧 Protótipo em desenvolvimento para fins acadêmicos (TCC).
